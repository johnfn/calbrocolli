# Calbrocolli: built demo

A calendar built in React with no calendar library. This branch holds only the compiled app, which GitHub Pages serves;
the source isn't published here.

Open the site, click an event to edit it, and use the Pages menu (top right) for Month, Year, Timeline, Day dial,
Planner, Find a time, Booking, Tidy, Insights, History, Import & share and Ask. Everything runs in your browser and
nothing is sent anywhere.
